# 👑 متجر حلويات السلطان الفاخرة | Al-Sultan Sweets E-Commerce Website

موقع متجر إلكتروني متكامل وعصري لبيع أرقى أصناف الحلويات الشرقية والغربية والشوكولاتة الفاخرة، مع دعم كامل للغة العربية (RTL)، سلة مشتريات تفاعلية، طلب مباشر عبر WhatsApp، وتوليد فواتير ضريبية مبسطة قابلة للطباعة.

---

## 🌟 مميزات ومحتويات المتجر

1. **قاعدة بيانات شاملة (24 صنف حلوى فاخر)**:
   - **حلويات شرقية**: كنافة نابلسية خشنة، بقلاوة بالفستق الحلبي، بسبوسة ملكية بالقشطة، حلاوة الجبن، معمول فاخر، زنود الست.
   - **كيك وحلويات غربية**: كعكة سان سيباستيان، تشيز كيك التوت، تيراميسو إيطالي، ماكرون فرنسي، إكلير باريسي، كيكة الفادج.
   - **شوكولاتة وترافل**: شوكولاتة دبي المقرمشة بالفستق والكنافة، ترافل سويسري، برالين بلجيكي.
   - **بوكسات هدايا ومناسبات**: بوكس ضيافة VIP الملكي، صواني مشكل العيد، بوكس ميني تارت.
   - **حلويات صحية ودايت**: معمول كيتو بدون سكر، كوكيز بروتين، بسبوسة الشوفان بالعسل.
   - **بوظة ومشروبات**: آيس كريم بوظة عربية بالقشطة والمستكة، دلة القهوة السعودية الملكية، كراميل ميكياتو.

2. **التجارة الإلكترونية والوظائف التفاعلية**:
   - 🛒 **سلة مشتريات ديناميكية (Cart Drawer + Cart Page)** مع حفظ البيانات تلقائياً في `localStorage`.
   - 🎁 **كوبونات خصم فعالة**: كود `SWEET20` (خصم 20%)، كود `RAMADAN` (خصم 25%)، كود `HALA10` (خصم 10%).
   - 💬 **الطلب الفوري والمباشر عبر WhatsApp**: يولد رسالة مفصلة بأسماء الأصناف والكميات والعنوان والإجمالي بضغطة زر.
   - 🧾 **توليد فاتورة ضريبية مبسطة قابلة للطباعة**: برقم تسلسلي وحساب الضريبة 15% والتوصيل.
   - 🔍 **محرك بحث وتصفية متقدم**: فلترة حسب الأقسام، السعر، وترتيب حسب الأكثر مبيعاً أو السعر.
   - 👁️ **نافذة المعاينة السريعة (Quick View Modal)** مع اختيار الأوزان وتحديث الأسعار لحظياً.
   - ❤️ **قائمة المفضلة (Wishlist)** لحفظ الأصناف المفضلة.
   - 🌓 **دعم الوضع الليلي والنهاري (Dark / Light Mode)**.

## 🚀 كيفية تشغيل وتصفح الموقع

الموقع مبني بتقنيات الويب القياسية (Pure HTML5, CSS3, JavaScript ES6+) دون الحاجة لتثبيت أي مكتبات أو سيرفرات معقدة:

1. قم بفك ضغط ملف `al-sultan-sweets-store.zip`.
2. انقر نقراً مزدوجاً على ملف `index.html` ليفتح في متصفحك مباشرة (Chrome, Edge, Safari, Firefox).
3. تصفح الأقسام، أضف الحلويات للسلة، جرب كود الخصم `SWEET20`، وجرب إتمام الطلب وتوليد الفاتورة!

## ⚙️ تخصيص إعدادات المتجر

يمكنك تعديل رقم الواتساب، العملة، أو إضافة أصناف جديدة بسهولة عبر فتح ملف `assets/js/products.js`:
- لتغيير رقم الواتساب: عدل `STORE_CONFIG.whatsappFormatted`.
- لتغيير العملة: عدل `STORE_CONFIG.currency`.
- لتعديل نسبة الخصم أو إضافة كود جديد: عدل كائن `COUPONS`.
