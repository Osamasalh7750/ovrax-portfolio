# منصة «مَنار» التعليمية لطلاب المدارس (Static Web Application)

منصة علمية متكاملة لطلاب المدارس صُممت لتعمل كـ **موقع Static نقي بدون أي خادم أو تثبيت حزم أو أدوات بناء**؛ حيث يكفي **النقر المزدوج على ملف `index.html`** لفتح المنصة والتنقل بين جميع أقسامها ونوافذها بكل سلاسة.

---

## 🌟 مميزات المنصة

1. **طريقة التشغيل الفورية (Zero Server Setup)**:
   - افتح المجلد وانقر نقراً مزدوجاً على `index.html`.
   - يعمل على أي متصفح (Edge, Chrome, Safari, Firefox).
   - لا مشاكل في أمان الـ CORS؛ لأن البنية خالية من تعقيدات التحميل الخارجي.
   - أيقونات SVG مدمجة بالكامل تعمل حتى في حال عدم الاتصال بالإنترنت.

2. **شروحات الدروس التفاعلية**:
   - تغطية المراحل الدراسية: **الابتدائية**، **المتوسطة (الإعدادية)**، **الثانوية**.
   - شروحات مفصلة خطوة بخطوة لمواد: الرياضيات، الفيزياء، الكيمياء، الأحياء، لغتي الجميلة، الذكاء الاصطناعي والحاسب.
   - كل درس يتضمن ملخصاً مركّزاً، خطوات حل، أمثلة وتطبيقات عملية، وسؤال تقييم ذاتي فوري مع شرح صحة الإجابة.

3. **نظام حجز المعلمين الخصوصيين (حضوري وأونلاين)**:
   - استعراض المعلمين المتخصصين مع التقييمات وسنوات الخبرة والرسوم.
   - خيارات حجز مرنة:
     - 🌐 **أونلاين (عن بعد)**: فصل تفاعلي ذكي.
     - 🏠 **حضوري في منزل الطالب**: مع إدخال العنوان والأحياء المدعومة.
     - 📍 **حضوري في مكان متفق عليه**: مثل المكتبات العامة أو المراكز التعليمية.
   - جدول تفاعلي لاختيار اليوم والوقت المناسب، وتأكيد الحجز الفوري مع حفظه في لوحة تحكم الطالب وإمكانية إلغائه.

4. **دورات المدارس المعتمدة والشريكة**:
   - برامج ومعسكرات مقامة بشراكة رسمية مع مدارس كبرى (مثل مدارس النور، ثانوية الرواد، مجمع الفكر والبيان، أكاديمية الأندلس).
   - توضيح المنهج، المدرسة، عدد المقاعد الشاغرة، وتواريخ الانطلاق.
   - إمكانية التسجيل الفوري وتوليد كود تسجيل وحفظه في حساب الطالب.

5. **المكتبة العملية وقارئ الكتب المدمج (In-App Reader)**:
   - كتب دراسية رسمية معتمدة لكل مرحلة.
   - مذكرات تفوق، أوراق عمل تفاعلية، ودليل التجارب العلمية المعملية.
   - قارئ رقمي مدمج يتيح تقليب الصفحات، استعراض الفهرس، وكتابة ملاحظات على الهامش تُحفظ تلقائياً في المتصفح.

6. **مشغل الفيديوهات التعليمية والكورسات**:
   - مشغل تفاعلي يحتوي على سبورة افتراضية للمفاهيم والمعادلات.
   - قائمة تشغيل الحلقات، وأهم النقاط المستفادة.
   - دفتر ملاحظات شخصي يرافق الطالب أثناء مشاهدة الدروس.
   - سؤال قياس فهم سريع بعد نهاية كل فيديو.

7. **لوحة تحكم الطالب الشخصية**:
   - متابعة الحجوزات القادمة مع المعلمين.
   - استعراض الدورات المدرسية المسجل بها.
   - إمكانية تعديل الملف الدراسي للطالب (الصف، المدرسة، المدينة، الهاتف).

8. **التصميم والراحة البصرية (ذوق أصيل وهادئ)**:
   - لوحة ألوان مستوحاة من ألوان الورق الطبيعي والعاج (`#F8F7F2`, `#FAF9F6`) مع الحبر الكحلي والزيتي الوقور (`#1C2733`, `#1E3A5F`, `#2B5740`).
   - خالية من الإبهار الزائد أو الإضاءات النيون المزعجة لضمان راحة العين أثناء المذاكرة الطويلة.
