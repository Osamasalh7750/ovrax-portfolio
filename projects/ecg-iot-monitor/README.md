## 📚 محتويات كل نظام (بيانات هندسية كاملة 100% غير منقوصة)

1. **المحاكي الحي في الوقت الفعلي (Interactive Simulator):** شاشات كانفاس وعدادات ومنزلقات وأصوات تنبيهية واقعية وأزرار تحكم ميداني.
2. **الدليل الهندسي المعمق (6 مراحل تنفيذية):** المبدأ الفيزيائي، التصميم الدائري، معالجة الإشارة الرقمية DSP، بروتوكولات إنترنت الأشياء والربط السحابي، أمان الأعطال، والإجراء التنفيذي.
3. **قائمة القطع والمكونات (BOM):** مواصفات فنية دقيقة، صور واقعية، أسعار تقريبية، وميزة تكبير وفحص الصور في مودال عالي الدقة.
4. **مخطط التوصيل السلكي الكامل (Wiring Table):** جدول كامل للأطراف مع دبابيس ESP32 و Arduino ومستويات الجهد وملاحظات الأمان.
5. **الكود البرمجي الكامل (Production C++ Code):** كود كامل 100% غير مختصر جاهز للنسخ الفوري أو التحميل المباشر كملف .ino.
6. **الاختبار المعرفي والهندسي (Interactive Quiz):** أسئلة اختيار من متعدد تفاعلية مع تصحيح فوري وشرح علمي مفصل.

1. esp32_ad8232_dsp_bpm.ino: كود ESP32 لمعالجة إشارة القلب وحساب الـ BPM وخوارزمية Pan-Tompkins.
2. rduino_ad8232_basic.ino: كود أردوينو الأساسي للـ ECG والتخطيط البياني.
3. esp32_adafruit_mqtt.ino: كود الربط السحابي للقلب عبر Adafruit IO MQTT.
4. esp32_blynk_iot.ino: كود الربط السحابي للقلب عبر Blynk IoT 2.0.
5. esp32_firebase_telemetry.ino: كود البث الطبي المشفر لقاعدة بيانات Firebase Realtime.
6. esp32_bme280_weather_station.ino: كود محطة الطقس BME280 عبر ناقل I2C.
7. esp32_pir_telegram_alarm.ino: كود الحراسة وتنبيهات بوت تيليجرام عبر SSL.
8. esp32_cam_surveillance_stream.ino: كود بث الفيديو الحي HTTP MJPEG وكشف الوجوه.
9. esp32_smart_ac_thermostat.ino: كود ريموت التكييف والترموستات بحساس DS18B20 و IR.
10. esp32_smart_irrigation_pump.ino: كود الري الآلي بحساس التربة السعوي وخوارزمية Soak & Cycle.
11. esp32_mq2_gas_fire_detector.ino: كود كشف الغاز وصمام الطوارئ الكهرومغناطيسي وحساب PPM.
12. esp32_pzem_energy_meter.ino: كود مقياس الطاقة PZEM-004T عبر Modbus-RTU.
13. esp32_rfid_access_control.ino: كود القفل الذكي وبطاقات RC522 عبر ناقل SPI.
14. esp32_smart_lighting_city.ino: كود إنارة الشوارع التكيفية مع خفت PWM وحساس LDR.
15. esp32_gps_fleet_tracker.ino: كود تتبع المركبات بنيو-6M وسياج جغرافي وخرائط قوقل.
16. esp32_ultrasonic_water_tank.ino: كود خزان المياه بالموجات فوق الصوتية JSN-SR04T وحماية التشغيل الجاف.
17. esp32_mq135_air_quality.ino: كود رصد جودة الهواء وحساب مؤشر AQI وتشغيل مروحة الفلترة.
18. esp32_hx711_smart_scale.ino: كود الميزان الصناعي 24-bit وتصفير Tare وجرد المستودع.
19. esp32_mpu6050_earthquake_alert.ino: كود رصد الزلازل MPU-6050 ومقياس ريختر وفصل صمامات الغاز.
20. esp32_smart_parking_tof.ino: كود المواقف الذكية وتوجيه السائقين بالليدات وحساب التعرفة.
21. esp32_egg_incubator_sht31.ino: كود الحاضنة الذكية وتحكم PID بالحرارة وتقليب البيض بالسيرفو.
22. esp32_aquaponics_water_quality.ino: كود الأكوابونيكس وجودة المياه وحموضة pH والعكارة والتهوية.
23. esp32_solar_tracker_ina219.ino: كود المتعقب الشمسي ثنائي المحور وقياس الجهد والتيار بشريحة INA219.
24. esp32_max30102_spo2_monitor.ino: كود قياس نسبة تشبع أكسجين الدم SpO2 ونبض القلب PPG السريري.
