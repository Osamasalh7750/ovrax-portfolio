# سوق النخبة | Elite Store 🛍️✨
### المتجر الإلكتروني العصري المتكامل (Static Double-Click Ready)

متجر إلكتروني فاخر بنظام **Static Web Application**، مُصمم ليعمل مباشرة بنقر مزدوج على ملف `index.html` في أي متصفح دون الحاجة لأي خوادم (Node.js/Apache/Python)، مع واجهات مستخدم غاية في الفخامة، سلة مشتريات تفاعلية، نظام إتمام طلبات، فواتير إلكترونية قابلة للطباعة، ولوحة تحكم إدارية شاملة لإدارة المنتجات والطلبات والمبيعات.

---

## 🌟 الميزات الرئيسية

### 1. واجهة المتجر للمتسوقين (Customer Storefront)
- **هوية بصرية فاخرة**: تصميم عصري يدعم اللغة العربية (RTL) بالكامل مع خط تجوال الراقي وألوان ملكية وتأثيرات حركية فائقة النعومة.
- **الوضع الداكن والفاتح (Dark / Light Mode)**: تبديل بلمسة زر مع حفظ اختيار المستخدم.
- **البحث الفوري الذكي**: نتائج بحث فورية منسدلة مع معاينات وصور المنتجات أثناء الكتابة.
- **تصفية متطورة**:
  - تصنيف حسب الفئات (إلكترونيات، عطور، ساعات، أزياء، قهوة مختصة).
  - فلتر نطاق السعر بشريط تمرير تفاعلي حي.
  - فلتر التوفر (المنتجات المتوفرة فقط في المخزون).
  - خيارات الترتيب (المقترح، الأرخص، الأغلى، الأعلى تقييماً، الاسم).
- **نافذة تفاصيل المنتج (Quick View Modal)**: استعراض المواصفات، الصور، التحقق من التوفر الفعلي في المخزون، واختيار الكمية.
- **سلة المشتريات الجانبية (Drawer Cart)**:
  - تحكم سلس بزيادة ونقصان الكميات وحذف العناصر.
  - شريط ديناميكي للشحن المجاني (يشجع العميل على إكمال الحد الأدنى للشحن المجاني).
  - نظام قسائم وكوبونات الخصم (جرب كود: `ELITE10` لخصم 10% أو `GOLD20` لخصم 20%).
  - حساب تلقائي وفوري للضريبة المضافة (15%) وتكلفة الشحن.
- **إتمام الشراء (Checkout Flow)**:
  - إدخال بيانات العميل والمدينة والعنوان.
  - خيارات دفع متنوعة (مدى / بطاقة ائتمانية، Apple Pay، الدفع عند الاستلام).
- **فاتورة إلكترونية معتمدة (E-Invoice)**:
  - توليد فاتورة ضريبية رسمية مبسطة مع محاكاة QR Code ورقم الطلب.
  - زر طباعة مخصص يحول الفاتورة مباشرة إلى PDF أو طباعة ورقية أنيقة.
- **تتبع الطلبات والشحنات (Order Tracking)**:
  - خط زمني تفاعلي من 4 مراحل (استلام الطلب -> التجهيز -> الشحن -> التسليم).
  - إمكانية البحث برقم الطلب (مثل: `ORD-8812`) أو برقم الجوال.
- **قائمة المفضلة (Wishlist)**: حفظ المنتجات وإدارتها وإضافتها إلى السلة بضغطة زر.

### 2. لوحة تحكم إدارة المتجر المتكاملة (Admin Dashboard)
يمكنك التبديل إليها بضغطة زر واحدة عبر الزر العلوي **"لوحة الإدارة"**:
- 📊 **نظرة عامة ومؤشرات حية (Overview)**:
  - إجمالي المبيعات والإيرادات الحقيقية.
  - عدد الطلبات المكتملة والمعلقة.
  - عدد المنتجات وتنبيهات المنتجات منخفضة المخزون (أقل من 5 قطع).
  - **رسم بياني تفاعلي للمبيعات الأسبوعية** مصمم بـ SVG نقي وخفيف الوزن.
  - جدول مصغر بأحدث الطلبات الواردة.
- 📦 **إدارة المنتجات (Products Management)**:
  - جدول كامل بالمنتجات وصورها وأسعارها ومخزونها.
  - **إضافة منتج جديد**:
    - يدعم **رفع صورة من جهاز الكمبيوتر مباشرة** عبر محول Base64 (لا يحتاج خادم!).
    - يدعم إضافة رابط صورة خارجي أو اختيار صورة من المكتبة السريعة.
    - تحديد الاسم، التصنيف، السعر، السعر قبل الخصم، المخزون، الشارة، والوصف.
  - **تعديل أي منتج** وحفظ التغييرات فوراً.
  - **حذف المنتجات** مع تأكيد فوري.
- 📑 **إدارة الطلبات والمبيعات (Orders Management)**:
  - تصفية الطلبات بحسب حالتها (الكل، قيد الانتظار، جارِ التجهيز، تم الشحن، تم التوصيل، ملغي).
  - **تغيير حالة أي طلب عبر قائمة منسدلة فورية**، وتحديث مؤشرات المبيعات تلقائياً.
  - فتح واستعراض الفاتورة الإلكترونية الخاصة بأي طلب وطباعتها.
- 🏷️ **الكوبونات والعروض (Coupons)**:
  - إنشاء أكواد خصم جديدة بنسب خصم وحد أدنى محدد.
  - حذف الكوبونات أو تفعيلها/تعطيلها.
- ⚙️ **إعدادات المتجر وقاعدة البيانات (Settings & Backup)**:
  - تعديل اسم المتجر، العملة، الضريبة، هاتف الدعم، وحد الشحن المجاني.
  - **تصدير نسخة احتياطية (Export JSON)**: تنزيل ملف بكافة بيانات المتجر بنقرة واحدة.
  - **استيراد بيانات (Import JSON)**: استعادة بيانات سابقة بسهولة.
  - **استعادة البيانات الافتراضية**: زر لإعادة ضبط المتجر على المنتجات والطلبات التجريبية.

## 🚀 طريقة التشغيل

1. توجه إلى المجلد:
   `C:\Users\ComputerWorld\.gemini\antigravity\scratch\ecommerce-static-store`
2. انقر نقراً مزدوجاً على ملف **`index.html`**.
3. سيفتح المتجر مباشرة في متصفحك الافتراضي (Chrome, Edge, Firefox, Safari) بكامل وظائفه وبدون أي متطلبات إضافية.
