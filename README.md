## 🌟 نبذة عن المنصة (OVRAX Core)
منصة وبوابة برمجية تفاعلية تمثل الهوية الرقمية ومعرض الأعمال المتقدم للمهندس **أسامة صالح**. صُممت المنصة وفق نمط بصري سيبراني مستقبلي (Cyberpunk / 3D Sci-Fi Core) باستخدام **Three.js** ومؤثرات صوتية رقمية مولدة عبر **Web Audio API**[cite: 1, 3, 6].

الموقع ليس مجرد سيرة ذاتية ثابتة، بل هو **كتالوج تفاعلي حي (Live Multi-Platform Showcase)** يستعرض أنظمة ومنصات تم بناؤها وتطويرها بشكل مستقل، مع إمكانية تجربة كل منظومة بشكل مباشر بملء الشاشة[cite: 1, 4].

## 🚀 معرض الأنظمة والمشاريع المدمجة (Live Showcase Catalog)

يضم المستودع مجموعة من المنصات التطبيقية التي يمكن تشغيلها ومعاينتها فورياً عبر مساراتها المباشرة:

1. **منصة العاصمة المؤسسية (Enterprise SaaS ERP):**
   * نظام سحابي لإدارة الشركات، الموارد البشرية، المبيعات، المشتريات، المخزون، والتقارير المالية[cite: 18].
2. **منصة صروح للعقارات والحلول الهندسية (SOROUH Platform):**
   * منظومة متكاملة لبيع وتأجير العقارات، مع حاسبة بناء ذكية، معالج ترميم، واستشارات هندسية[cite: 17].
3. **منصة الصفوة لتأجير السيارات الفاخرة (Safwa Car Rental):**
   * نظام حجز فوري بمطارات ومدن المملكة، فلاتر لـ 20 ماركة عالمية، لوحة تحكم إدارية، ودعم متعدد اللغات[cite: 16].
4. **منصة مَنار التعليمية (Manar Educational Platform):**
   * منصة تعليمية لطلاب المدارس تشمل حجز معلمين، دورات مدارس معتمدة، وقارئ مذكرات إلكتروني مدمج[cite: 15].
5. **مول النخبة للأزياء والملابس (Grand Fashion Mall):**
   * سوق أزياء يضم 120 تشكيلة لجميع أفراد العائلة، مع دليل طوابق وحاسبة مقاسات ذكية[cite: 14].
6. **منصة شفاء الطبية لكبار الجراحين (ShifaSurgeons Platform):**
   * منصة تخصصية لحجز 60 جراحاً استشارياً لـ 20 عملية دقيقة، مع حجز تفاعلي وإصدار تذاكر رقمية بالباركود[cite: 13].
7. **متجر سوق النخبة (Elite Store):**
   * متجر إلكتروني للساعات والأجهزة العصرية مع لوحة إدارة متكاملة (Admin Dashboard) وتتبع للشحنات[cite: 12].
8. **منصة أثير للمناسبات والشاليهات VIP:**
   * نظام حجز قاعات وشاليهات مدعوم بعارض 3D بزاوية 360° وحاسبة أسعار فورية ومخطط توزيع طاولات[cite: 11].
9. **متجر حلويات السلطان الفاخرة:**
   * واجهة متجر حلويات شرقية وغربية بسلة منزلقة ونظام طلب مباشر وفاتورة واتساب[cite: 10].
